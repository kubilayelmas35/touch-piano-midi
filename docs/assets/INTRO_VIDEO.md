# StaveFlow — açılış videosu

`assets/intro.mp4` veya `assets/intro.webm` dosyasını buraya koyun (kısa, sessiz, ~5–15 sn önerilir).

- **Electron:** `assets/` klasöründen okunur.
- **Web / Wix:** `npm run build:pages` sonrası `docs/assets/` altına kopyalanır.

Video yoksa aurora animasyonlu splash otomatik gösterilir.
